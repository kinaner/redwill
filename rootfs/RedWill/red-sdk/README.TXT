RedWill SDK - examples
======================
.rpp = RedWill script (source text)      .rxe = RedWill executable (compiled)

Run an example:   double-click a .rxe in the Explorer, or in the Terminal:  run hello
Edit an example:  select a .rpp, click "Edit" (opens Notepad), change it, press "Run".
Compile a script: Terminal:  rppc hello.rpp        -> creates hello.rxe
                  On your PC:  build/rppc hello.rpp  (see README.md in the source)
Full reference:   C:\RedWill\red32\API.TXT

hello.rpp     console program (prints in the Terminal)
window.rpp    a window with a label and buttons
adder.rpp     text boxes + a button
canvas.rpp    drawing with the mouse (custom painting)
clock.rpp     timer events
files.rpp     list box + file functions
notes.rpp     Open / Save As dialogs
catch.rpp     small keyboard game
